# Employee Salary Management

## 📌 Project Overview

This is an independent Excel project created to practice and apply fundamental Excel skills learned during my Data Analyst learning journey.

The project simulates a monthly employee payroll system, including working hours, overtime, bonuses, gross salary, tax, and net salary calculations.

## 🎯 Project Objectives

- Calculate employee salaries based on hours worked and hourly wage
- Calculate overtime hours
- Apply conditional bonuses
- Calculate gross salary
- Calculate tax using an absolute cell reference
- Calculate net salary
- Analyze salary data using basic Excel functions

## 🛠️ Excel Skills Used

- Rows and Columns
- Cell References
- Relative References
- Absolute References (`$`)
- Basic Formatting
- `SUM`
- `AVERAGE`
- `MIN`
- `MAX`
- `IF`
- Percentage calculations
- Overtime calculations
- Salary calculations

## 📊 Payroll Rules

- Normal monthly working hours: **160 hours**
- Overtime is calculated for hours worked above 160
- Employees working 180 or more hours receive a bonus of **$200**
- Tax rate: **12%**
- Net Salary = Gross Salary − Tax

## 📈 Summary Analysis

The spreadsheet includes:

- Maximum salary
- Minimum salary
- Average salary
- Total hours worked
- Total overtime hours
- Total bonuses
- Total gross salary
- Total tax
- Total net salary

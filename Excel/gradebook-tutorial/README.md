Gradebook (Tutorial)
📌 Project Overview
This project was completed by following a video tutorial to learn and practice new Excel functions and features.
The spreadsheet simulates an employee/student gradebook, scoring test results and flagging failing scores using conditional logic and formatting.

🛠️ Excel Skills Used

* Percentage calculations
* `OR` formula
* Conditional Formatting
* Charts
* `SUM`
* `AVERAGE`
* `MIN`
* `MAX`
* Absolute References (`$`)

📊 Logic

* Each test score is converted to a percentage of points possible
* `OR` formula is used to flag a record when any one of multiple conditions is met (e.g. failing a required test)
* Conditional Formatting highlights low scores and flagged rows automatically
* Charts visualize scores across all test categories

📈 Summary Analysis
The spreadsheet includes:

* Maximum, Minimum, and Average scores per test category
* Bar charts for each test category

📁 File

* `gradebook.xlsx`

💡 What I Learned
This was a guided/tutorial project used to learn the `OR` formula, Conditional Formatting, and Charts before applying them independently in later projects.
